오늘 데일리의 리드는 Amazon의 3분기 실적이다. 이로써 Alphabet·Microsoft에 이어 3대 클라우드 회사의 실적이 모두 나왔다. AWS 매출은 39% 늘었지만, 분기 설비투자가 $773억까지 불어나 최근 12개월 잉여현금흐름은 적자로 돌아섰다. 하루 앞서 실적을 낸 Alphabet은 10/29(미국) 정규장에서 12% 넘게 떨어져 마감했다. 하루 낙폭으로는 사상 최대다(CNBC 보도). 같은 날 Nasdaq 종합지수는 1.4% 내렸다(Yahoo Finance 보도). 10/30에는 Nasdaq 종합지수가 2.9% 내려 6월 이후 가장 크게 떨어졌다(Reuters 보도). 클라우드 성장보다 투자 부담에 시장이 더 민감하게 반응하는 흐름이 이틀째 이어졌다. 이어 Mistral Large 4의 가중치 공개, GitHub Universe에서 정식 출시된 Copilot Fusion, 데이터센터·AI 부문이 78% 성장한 Intel 실적을 다룬다.

용어 풀이 — 잉여현금흐름(FCF)은 영업으로 번 현금에서 설비투자를 뺀 값으로, 회사가 실제로 손에 쥐는 현금이다. 가이던스는 회사가 다음 분기 실적을 스스로 내다본 전망치다. 오픈웨이트(open-weight)는 학습이 끝난 모델 가중치를 공개해 누구나 내려받아 실행할 수 있게 한 것이다. MoE(전문가 혼합)는 전체 파라미터 가운데 일부 '전문가'만 골라 계산하는 구조로, 총 크기에 비해 실제 연산량이 작다. MaaS(Model as a Service)는 모델을 API 등으로 남에게 서비스하는 사업을 말한다. 모델 라우팅은 작업에 맞춰 여러 AI 모델 가운데 어떤 것을 쓸지 자동으로 고르는 기능이다.

편집 노트 — 주가는 10/30(미국) 정규장 종가 기준 보도 수치이며, 시간외 등락은 따로 표시했다. 실적 수치는 각 사 SEC 8-K 보도자료 원문을 따랐고, 컨퍼런스콜 발언과 언론 보도 수치는 "보도 기준"으로 따로 표시했다. 벤치마크 점수는 모두 각 사 자체 발표다. 본 매체는 Anthropic 모델(Claude) 위에서 운영된다. Amazon은 Anthropic의 투자자이고, §2·§3에는 Claude와의 비교 수치가 나온다. 이 항목들과 단신②는 발표 사실만 옮겼고, 평가는 하지 않았다.

1. [실적] Amazon 3분기 — AWS 매출 $460억(+39%), 분기 설비투자 $773억, 12개월 잉여현금흐름 −$424억

카테고리: 기업동향 · 2026-10-29(미국, Amazon 실적 발표)

Amazon이 10/29(미국) 장 마감 후 9/30 마감 분기 실적을 발표했다. 순매출은 $2,019.44억으로 1년 전($1,801.69억)보다 12% 늘었고, 영업이익은 $280.76억(전년 $174.22억)이었다. 클라우드 부문 AWS 매출은 $459.84억으로 39% 늘었다(전년 $330.06억). TechCrunch 등은 이를 5년 가까이 만의 가장 빠른 성장이라고 보도했다.

  • AWS 수익성: AWS 영업이익은 $177.73억(전년 $114.34억)으로, 영업이익률은 38.7%(전년 34.6%)다. 회사는 AWS의 연 매출 환산 규모가 $1,840억이라고 밝혔다.
  • 다른 부문: 북미 매출 $1,128.52억, 국제 매출 $431.08억이다. 광고 매출은 $196.37억으로 11% 늘었다(환율 영향 제외 +12%).
  • 순이익은 감소: 순이익은 $206.85억(전년 $211.87억), 희석 주당순이익(EPS)은 $1.89(전년 $1.95)였다. 1년 전 3분기에는 Anthropic 투자 평가이익 $95억(세전)이 영업외이익으로 잡혀 있었기 때문이다.
  • 설비투자와 현금흐름: 이번 분기 유형자산 취득(설비투자)은 $772.59억으로 1년 전($350.95억)의 두 배를 넘었다. 최근 12개월 기준 영업현금흐름 $1,683.00억에서 설비투자(매각·인센티브 차감) $2,106.57억을 뺀 잉여현금흐름은 −$423.57억이다. 1년 전 같은 기간에는 +$147.88억이었다.
  • 4분기 가이던스: 순매출 $2,400억~$2,470억(+1216%), 영업이익 $285억$335억이다. Yahoo Finance에 따르면 시장 예상치(매출 $2,445억, 영업이익 $331억)가 가이던스 중간값보다 높았다.
  • AI 관련 발표 (회사 주장): Amazon은 AI 모델 서비스 Bedrock의 전체 토큰 처리량이 "거의 17배(nearly 17x)" 늘었다고 밝혔다. Bedrock에는 Claude Fable 5.1·Opus 5.5·Sonnet 5.5·Haiku 5.5가 추가됐고, OpenAI 모델 기반 관리형 서비스 'Bedrock Managed Agents'가 공개 프리뷰로 나왔다.
  • 발언 (보도자료 원문): 앤디 재시(Andy Jassy) CEO는 "AWS의 기능과 인프라 투자가 효과를 내고 있으며, 3분기 매출이 전년 대비 39% 넘게 늘었다(Our AWS investment in functionality and infrastructure is working, with over 39% year-over-year revenue growth in Q3)"고 말했다.
  • 컨퍼런스콜 (보도 기준): TechCrunch에 따르면 회사는 2026년 현금 설비투자 약 $2,200억 전망을 유지했고, 2027년에는 이보다 "의미 있게 더(meaningfully more)" 쓰겠다고 밝혔다.
  • 주가: Amazon 주가는 10/29 시간외 거래에서 약 6% 떨어진 뒤(TechCrunch 보도), 10/30 정규장에서는 낙폭을 줄여 약 1.4% 하락했다(CNBC·Reuters 보도).

2. [오픈웨이트] Mistral Large 4 가중치 공개 — 약 1T/52B, 컨텍스트 1M, MaaS 사업자만 별도 계약

카테고리: 오픈소스 · 2026-10-29(Mistral 발표·Hugging Face 공개)

Mistral이 10/6 프리뷰로 내놓았던 Mistral Large 4의 가중치를 10/29 Hugging Face에 공개했다. 저장소에 안내돼 있던 공개 예정일(10/31)보다 이틀 앞당겨졌다. 같은 날 블로그 글 "Le Chonk: Built for Coders, Trusted by Defenders"에서 정식 버전의 변경 사항도 밝혔다.

  • 사양 (모델 카드): 총 파라미터 약 1조(1T), 토큰마다 실제로 쓰는 활성 파라미터 약 520억(52B)인 MoE 모델이다. 128개 전문가 중 4개와 공유 전문가 1개를 쓴다. 컨텍스트는 100만 토큰, 지원 언어는 160개가 넘는다. Nvidia Blackwell용 저정밀(NVFP4) 체크포인트도 함께 올라왔다.
  • 라이선스 (LICENSE 원문): 이름은 'Mistral Ecosystem Open-Weight License'로, MIT 라이선스를 고친 것이다. 사용·수정·배포·재학습·상업 이용을 허용한다. 다만 MaaS 사업을 하는 라이선시는 상업적으로 쓰기 전에 Mistral과 별도 상업 라이선스를 맺어야 한다. 여기서 MaaS는 제3자가 API나 호스팅 엔드포인트를 통해 모델의 입력·파라미터·학습 데이터를 실질적으로 통제할 수 있게 제공하는 것을 뜻한다. 내부 사용과 Mistral 공식 제품을 통한 이용은 이 조건의 예외다. 이전 모델 Medium 3.5와 달리 매출 상한 조항은 없다.
  • API 가격: 100만 토큰당 입력 $0.70, 캐시 입력 $0.07, 출력 $2.10이다.
  • 성능 (Mistral 자체 발표): Artificial Analysis Coding Agent Index 48%로 GLM-5.3과 비슷하다고 밝혔다. Terminal-Bench 4.0은 41%로 프리뷰(28%)보다 13%p 올랐다. 악성 사이버 요청 거부율은 평균 96.6%라고 했다.
  • 프리뷰 대비 변경: 강화학습을 더 했고, 추론 강도를 Low·Medium·High 3단계로 고를 수 있게 했다(기본 High). 사이버보안 특화 변형은 Orange Cyberdefense 등 설계 파트너에게만 프리뷰로 준다.
  • 발언 (블로그 원문): Mistral은 "Mistral Large 4는 코딩용 오픈웨이트 모델 중 최고(Mistral Large 4 ranks as the best open-weight model for coding)"이며 "처음부터 끝까지 유럽 인프라에서 학습했다(Trained from scratch on European infrastructure)"고 적었다.

지금까지 최상위권 오픈웨이트 모델은 대부분 중국 연구소에서 나왔다. 1조 파라미터급 유럽 모델이 내려받을 수 있는 형태로 나오면서, 데이터를 밖으로 보내기 어려운 기업·기관에 선택지가 하나 늘었다. 다만 모델을 API로 재판매하려는 클라우드·호스팅 사업자는 별도 계약이 필요하므로, 라이선스 원문을 먼저 확인해야 한다.

3. [제품] GitHub Universe — Copilot Fusion 정식 출시, Enterprise에 Copilot 포함·사용량 과금

카테고리: 제품 · 2026-10-28(미국, GitHub Universe 2026)

GitHub이 10/28(미국) 연례 행사 Universe 2026에서 작업마다 AI 모델을 골라 조합해 실행하는 Copilot Fusion을 정식 출시(GA)했다. GitHub Enterprise 고객이 별도 좌석 없이 Copilot을 쓰고 사용량만큼 내는 과금 방식도 함께 발표했다.

  • Copilot Fusion: 작업에 추론·코드 생성·디버깅·도구 사용 중 무엇이 필요한지 판단해, 하나 또는 여러 모델로 나눠 실행한다. 강도는 Standard·High·Max 3단계, 실행 방식은 한 모델(Single), 순차 연결(Cascade), 다른 모델의 검토(Critique) 3가지다. 모든 Copilot 플랜에서 VS Code·GitHub Copilot 앱·Copilot CLI·JetBrains로 쓸 수 있다.
  • 과금: Fusion이 쓴 각 모델의 표준 요금(standard rate)으로 차감된다. 유료 플랜 사용자는 한시적으로 모델 비용 30% 할인을 받는다. 종료일은 공개되지 않았다.
  • 성능 (GitHub 자체 발표): GitHub은 Fusion Max가 Artificial Analysis Coding Agent Index에서 60점을 받아 "Claude Code with Opus 5.5 Max"와 2점 이내였고, 과제당 평균 비용은 약 절반이었다고 밝혔다. 비교 대상이 Anthropic 제품이어서 본 매체는 수치만 옮긴다.
  • GitHub Enterprise에 Copilot 포함: GitHub 또는 Microsoft 계정팀과 거래하는 GitHub Enterprise Cloud 고객은 라이선스 사용자 전원이 별도 Copilot 구독 없이 Copilot을 쓸 수 있다. AI 사용량은 첫 요청부터 기업 예산에서 차감된다. 예산이 바닥나도 코드 자동완성은 계속되지만, Chat·코드 리뷰·클라우드 에이전트는 예산이 있어야 한다. 셀프서브 고객에게는 몇 주에 걸쳐 단계적으로 열린다. 기존 Copilot Business·Enterprise 플랜도 계속 판매한다.
  • Octoverse 2026 (GitHub 발표): 에이전트가 첫 초안을 쓴 PR의 비중이 3월 17%에서 9월 40% 넘게 늘었다. GitHub이 감지할 수 있는 에이전트만 센 값이라 실제보다 낮을 수 있다. 9월에 모델을 직접 고른 Copilot 사용자의 61%는 두 개 이상의 모델을 썼다.

Intel이 10/29(미국) 장 마감 후 3분기 실적을 발표했다. 매출은 $165억으로 1년 전($137억)보다 21% 늘었다. 일회성 항목을 뺀 non-GAAP 매출총이익률은 44.1%(전년 40.0%), non-GAAP 희석 EPS는 $0.52(전년 $0.23)였다. GAAP 기준 EPS는 $0.60(전년 $0.90)이다.
