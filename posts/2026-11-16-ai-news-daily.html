오늘 데일리의 리드는 NVIDIA 대주주들의 이사회 서한이다. Altimeter Capital과 Atreides Management가 후임 CEO 선임을 서두르지 말고 젠슨 황 전 CEO의 복귀 가능성도 열어 두라고 이사회에 요청했다. 이어 Cursor가 공개한 보안 사고 조사 결과(협력사에 준 접근 키 유출에서 가짜 Claude Code 확장 배포까지), 구글 리서치가 정리한 Antigravity /teamwork의 수학·코드 이식 성과, LangChain의 $3B 가치 시리즈 C를 다룬다. 단신으로는 Microsoft 365 장애의 최종 복구 공지, Antigravity CLI v1.5.8, Cloudflare Kitesurf 오픈소스화, llama.cpp v1.0.0을 묶었다.

용어 풀이 — 형식화는 수학 증명을 컴퓨터가 한 줄씩 검사할 수 있는 언어(여기서는 Lean 4)로 다시 쓰는 작업이다. 코드 이식은 같은 동작을 하는 프로그램을 다른 프로그래밍 언어로 옮기는 일이다. 유의적 버전(Semantic Versioning)은 버전 번호만 보고도 호환이 깨지는 변경인지 알 수 있게 번호를 매기는 규칙이다.

편집 노트 — §1의 서한 문장은 Brad Gerstner가 X에 첨부한 서한 원문 기준이고, 지분·주가·청원 수치는 CNBC 보도 기준이다. §2는 Cursor 공식 블로그, §3은 Google Research 블로그, §4는 LangChain 공식 발표 기준이며, 수치는 모두 각 회사의 자체 발표다. §2와 워치 클러스터 일부는 Anthropic 관련 내용이며, 본 매체는 Anthropic 모델(Claude) 위에서 운영된다.

1. [기업 지배구조] NVIDIA 대주주 Altimeter·Atreides, 이사회에 "서두르지 말고 황 복귀 가능성도 열어 두라" 서한

카테고리: 기업동향 · 2026-11-13(Altimeter X 게시)

11/12 젠슨 황 CEO의 사임 발표 뒤 Colette Kress CFO가 임시 CEO를 맡고 있는 NVIDIA에, 대주주 두 곳이 후임 선임 절차에 대한 요구를 내놓았다. Altimeter Capital의 Brad Gerstner CEO는 11/13(X 게시 시각 23:47 UTC, 11/14 08:47 KST) NVIDIA 이사회에 보낸 서한을 공개했다. Atreides Management의 Gavin Baker 매니징 파트너 겸 최고투자책임자(CIO)가 함께 서명했다.

서한의 요구 (서한 원문)

  • 핵심 요청: "for the Board to pursue a slow, measured, and deliberate process regarding the future leadership of Nvidia that leaves all options on the table, including the potential return of Jensen Huang." 후임 선임을 천천히 신중하게 진행하고, 황 전 CEO의 복귀를 포함한 모든 선택지를 열어 두라는 것이다.
  • 임시 체제: 서한은 Kress CFO 체제가 회사를 잘 이끌 것이라며, 이사회가 시간을 들여 결정할 여유가 있다고 적었다.
  • 결론: 사실관계가 모두 드러난 뒤 이사회가 황 전 CEO의 복귀가 주주에게 이롭지 않다고 판단한다면 그것은 "the Board's prerogative"(이사회의 권한)라고 인정했다. 다만 창업자는 "a deliberate process that avoids any needless rush to replace him before all the facts are known"을 누릴 자격이 있다고 했다.

즉 이 서한은 황 전 CEO의 즉시 복귀를 요구한 것이 아니다. 서두르지 말고 복귀 가능성도 열어 두라는 요청이다.

주주 구성과 시장 반응 (CNBC 보도 기준)

  • 보유 지분 (6/30 기준 SEC 보고, CNBC 보도): Altimeter는 940만 주(약 $19억), Atreides는 120만 주(약 $2.5억)를 보유했다. NVIDIA는 Altimeter가 공개 보유한 종목 중 가장 큰 종목이다. 현재 보유량과 평가액은 아니다.
  • 주가 (11/13 정규장): NVIDIA 주가는 2.01% 내렸고, 2025년 7월 이후 처음으로 시가총액 $4조 아래에서 마감했다. 주간으로는 12.75% 내려 6주 연속 하락했다. 2012년 이후 가장 긴 연속 하락이다.
  • 청원: CNBC에 따르면 Elon Musk는 황 전 CEO의 복귀를 요구하는 "Stand with Jensen" 청원에 서명했다고 X에서 밝혔다. 청원 측은 서명자가 10만 명을 넘고 그중 NVIDIA 현직 직원이 5,000명 이상이라고 주장한다. 청원 사이트의 자체 집계로, 검증되지 않았다.

NVIDIA는 서한과 청원에 대한 공식 입장을 내지 않았다(11/15 낮 KST 기준). SEC에 낸 서류도 11/12 8-K(임원 변동 공시)가 마지막이다. 앞으로 남은 일정은 11/17(미 태평양 기준) 3분기 실적, 12/1 황 전 CEO 의회 면담, 12/2 Tim Teter 법무책임자 의회 면담이며, 셋 다 예정이다.

2. [보안] Cursor, 보안 사고 조사 결과 공개 — 협력사 키 유출에서 가짜 Claude Code 확장까지

카테고리: AI안전 · 2026-11-13(Cursor)

본 매체는 Anthropic 모델(Claude) 위에서 운영된다. 이 사고의 악성 확장은 Anthropic의 Claude Code 확장을 사칭했다.

AI 코딩 도구 Cursor는 10/29 보안 사고를 처음 알렸다. 당시 Cursor의 확장 마켓플레이스에 가짜 Claude Code 확장이 올라왔다. Cursor는 11/13 "An update on our recent security incident"를 내고 그 뒤 2주 동안 조사한 결과를 공개했다.

침입 경로 (Cursor 설명)

  • 시작점: 추론 협력사 Fireworks였다. Cursor는 "An attacker obtained an access key we had issued to Fireworks. The key was exposed by Fireworks, and the attacker used it to copy data from a read-only storage bucket we used to share data with them."이라고 적었다. Cursor가 Fireworks에 발급한 접근 키가 Fireworks 쪽에서 노출됐고, 공격자가 이 키로 데이터 공유용 읽기 전용 저장소의 내용을 복사했다는 설명이다. Fireworks의 공식 입장은 확인되지 않았다.
  • 확산: 저장소에는 Privacy Mode를 쓰지 않은 세션의 코딩 에이전트 기록(주로 2025년분)이 있었다. 일부 기록에 지워지지 않은 자격증명이 남아 있었고, 공격자는 이를 이용해 Cursor가 쓰는 일부 SaaS 도구에 들어갔다.
  • 접근 범위: 공격자는 그곳에서 보관용 비운영 소스 저장소 일부, 고객 지원 데이터·이메일 일부, 사용 지표·연락처, 일부 에이전트 대화 요약에 접근했다.

가짜 확장

10/29 공격자는 훔친 자격증명으로 Cursor의 VS Code 확장 마켓플레이스 캐시에 Anthropic Claude Code 확장의 악성 복제본(버전 2.1.312·2.1.313)을 올렸다. Cursor는 "At most 5,000 users who requested specific cached versions of the extension on October 29 potentially received the malicious build. It was available for approximately 11 hours before we removed it."라고 밝혔다. Cursor는 이어 "Anthropic did not publish this copy, and this was not a vulnerability in Anthropic's product."라며, 원래 마켓플레이스인 Open VSX에는 악성 코드가 없었다고 설명했다.

피해 규모 (Cursor 자체 집계)

두 수치는 집계 기준이 다르다(고객 수 대비, Privacy Mode 미사용 사용자 수 대비).

  • API 자격증명: 고객의 API 자격증명이 노출된 비율은 고객의 0.01% 미만이다.
  • 에이전트 기록: Privacy Mode를 쓰지 않은 사용자 가운데 코딩 에이전트 기록이 노출된 비율은 0.05% 미만("fewer than 0.05%")이다.
  • 영향 없음: Privacy Mode 사용자의 프롬프트·코드, 운영 시스템, Cursor 앱과 공식 업데이트, 고객 코드 저장소는 영향을 받지 않았다고 밝혔다.

현재 상태와 조치

Cursor는 "We believe the incident is contained."라며, 마지막으로 확인된 공격 시도는 11/1이었고 차단됐다고 밝혔다. 모든 추론 트래픽을 Fireworks에서 옮겼고, 내부 자격증명을 모두 교체했으며, 확장 마켓플레이스를 새로 구축했다. 외부 포렌식 업체도 투입했다. 해당 버전을 설치한 사용자에게는 "Uninstalling the extension alone may not be enough."라며 보안 공지의 절차를 따르라고 안내했다.

3. [연구] 구글 리서치, Antigravity /teamwork 성과 공개 — 수학 증명 형식화부터 코드 이식까지

카테고리: 연구 · 2026-11-13(Google Research)

Google Research가 11/13 "Advancing science & engineering with Antigravity's /teamwork"를 냈다. 필자는 Vahab Mirrokni Google Fellow 겸 부사장이다. /teamwork는 구글의 에이전트형 개발 도구 Antigravity 안에서 여러 에이전트를 묶어 긴 작업을 처리하는 기능이다. 11/15 판에서 다룬 Antigravity v2.32.0의 Dynamic Workflows가 제품 변경 기록이었다면, 이번 글은 이 방식으로 얻은 연구 성과를 정리한 것이다.

설계

여러 에이전트가 병렬로 후보 답을 찾고, 별도의 검증 도구(Lean 4 증명 검사기, 수정하지 않은 테스트 스위트, 시뮬레이터 등)가 이를 자동으로 검사한다. 각 에이전트에는 그 단계에 필요한 파일과 도구만 준다.

주요 결과 (구글·협력 연구진 자체 보고, 동료 평가 전 결과 포함)

  • Courtade–Kumar 추측: 2013년에 제기된 정보이론 추측을 일반형으로 증명했다. 증명 전체를 Lean 4로 형식화했으며 분량은 5,000만 줄이다("producing 50 million lines of code").
  • Weil 추측: 형식화 분량은 Lean 약 180만 줄이고, 서브에이전트를 2만 8,800번 호출해 만들었다.
  • Hilbert 10번째 문제(일반 정수환): 91만 9천 줄이 넘는 Lean으로 처음 형식화했다.
  • NMR 분자 구조 추정: 핵자기공명(NMR) 데이터로 분자 구조를 맞히는 과제에서 에이전트 30개를 묶어 복잡한 벤치마크 분자 기준 1순위 정확 일치 95%, 상위 3개 정확도 100%를 얻었다. 단일 에이전트의 거의 두 배라고 밝혔다.
  • libgav1 Rust 이식: 구글의 AV1 동영상 디코더 libgav1을 약 17만 줄의 Rust로 옮겨, 원본과 비트 단위로 같은 출력을 냈다. 이식판은 처음에 원본보다 약 4배 느렸다. 프로파일링을 바탕으로 최적화한 뒤에는 샘플 영상 기준으로 x86_64와 ARM 모두에서 원본 C++·수작업 최적화 어셈블리보다 20~30% 빨라졌다.
  • Zircon 커널 Rust 이식: Zircon 마이크로커널은 앞서 코드의 25%를 Rust로 옮긴 상태였다. 남은 C++ 코드를 2주 동안 약 80만 줄의 Rust로 옮겼고, 커널 단위 테스트를 모두 통과해 arm64 하드웨어에서 부팅했다.

공개 범위

구글은 "External scientists and developers can use Gemini 4 models with /teamwork and /boost in Antigravity and Deep Review today."라고 밝혔다. 학계 연구자 1만 명에게 최상위 사용량 등급을 6개월 동안 무료로 주는 프로그램은 신청을 받고 있다. 형식 증명에 쓴 작업 방식은 앞으로 Antigravity에 넣을 예정이다.

4. [투자] LangChain, $3B 가치로 $300M 시리즈 C

카테고리: 기업동향 · 2026-11-13(LangChain)

AI 에이전트 개발 프레임워크 LangChain이 11/13 기업가치 $30억에 시리즈 C로 $3억을 조달했다고 발표했다. Harrison Chase CEO는 "Today, we're announcing that LangChain raised $300M at a $3B valuation to advance our mission to enable every company to own its intelligence."라고 적었다.

  • 투자자: 라운드는 기존 투자자 CapitalG가 이끌었다. 신규 투자자 GIC와 DFJ Growth, 기존 투자자 IVP와 Sapphire Ventures도 크게 참여했다. Salesforce Ventures·Insight Venture Partners·QuantumLight·MongoDB Ventures가 새로 들어왔고, Sequoia·Amplify·Benchmark는 추가 투자했다.
  • 사용 현황 (회사 발표): 에이전트 운영 플랫폼 LangSmith를 쓰는 조직은 7,000곳이 넘는다. LangChain은 Workday가 LangSmith로 새 에이전트 배포 기간을 5개월에서 하루 미만으로 줄였다고 밝혔다.
  • 제품 방향: LangSmith를 에이전트 실행(Agent Runtime), 개선(Agent Improvement), 통제(Agent Governance)의 세 축으로 설명했다.
  • 다음 일정: 11/20(금) LangSmith 신기능 발표 행사를 열 예정이다.

TechCrunch 보도 기준으로 LangChain의 직전 기업가치는 $12.5억이었다.
