오늘 데일리의 리드는 OpenAI의 ChatGPT Wallet이다. ChatGPT의 에이전트가 사용자 승인을 거쳐 실제로 물건값을 치르는 기능이다. 이어 GitHub Copilot이 Gemini 4 Hydrogen을 정식 도입하고 12/14에 모델 6종을 퇴역시키겠다고 예고한 소식, EU 27개국 정상이 AI를 단독 의제로 더블린에서 연 비공식 회의, Google Antigravity의 Dynamic Workflows, Anthropic의 안전 평가 설계 방법론 글을 다룬다. 단신으로는 Gemini 앱의 Google Wallet 연결, Codex CLI·Claude Code 업데이트, Microsoft 클라우드 장애를 묶었다.

용어 풀이 — 에이전트는 사용자 대신 여러 단계의 작업을 스스로 이어서 처리하는 AI 기능이다. 토큰화 결제는 실제 카드 번호 대신 거래마다 새로 발급한 대체 번호로 결제하는 방식이다. 서브에이전트는 큰 작업을 나눠 맡는 하위 에이전트다. 퍼센트포인트(%p)는 두 비율의 단순한 차이를 뜻한다(예: 94%와 60%의 차이는 34%p).

편집 노트 — §1은 OpenAI 공식 요약 문장을 확인했고, 플랜·파트너·수수료 같은 세부 조건은 CNBC 보도 기준이다. §2·§4는 GitHub·Google의 공식 변경 기록 기준이다. §3은 EU 이사회 원문을 직접 열람하지 못해 확인된 사실만 옮겼다. §5와 단신 일부는 Anthropic 관련 내용이며, 본 매체는 Anthropic 모델(Claude) 위에서 운영된다. Microsoft 장애 단신은 Microsoft 공식 X 게시와 TechCrunch 보도 기준이다.

1. [제품] OpenAI, ChatGPT Wallet 출시 — 에이전트가 사용자 승인을 받아 결제

카테고리: 제품 · 2026-11-13(OpenAI)

OpenAI가 11/13(OpenAI 뉴스 RSS 기준 15:00 GMT, 11/14 00:00 KST) ChatGPT Wallet을 발표했다. OpenAI의 공식 요약은 이 기능을 "a secure way for agents in ChatGPT Work, Codex, and dots to complete purchases with user approval and existing card protections"라고 설명한다. 적용 대상은 dots만이 아니라 ChatGPT Work·Codex·dots의 에이전트다. OpenAI 발표 본문은 본 매체가 직접 열람하지 못했다.

세부 조건 (CNBC 보도 기준)

  • 제공 범위: 우선 미국의 Pro 구독자 중 18세 이상에게 제공한다. 결제 네트워크 파트너는 American Express·Mastercard·Visa다.
  • 결제 방식: 카드 정보는 한 번만 입력하고, 구매할 때마다 보안 확인을 거쳐 사용자가 승인한다. 에이전트는 카드 정보를 보지 못하며, 결제 네트워크가 거래마다 따로 쓰는 토큰(전용 카드 번호·보안 코드·만료일)을 발급한다. 기존 카드 혜택과 보호는 유지된다.
  • 수수료: 출시 시점에는 OpenAI가 거래 수수료를 받지 않는다.

CNBC에 따르면 OpenAI 결제·수익화 제품 책임자 Chaya Nayak은 "It's going to take time for the ecosystem to build the right infrastructure"라고 말했고, Amex의 Luke Gebb 부사장은 제한된 환경에서 먼저 시작해 지켜보는 것이 맞다는 취지로 말했다. 같은 보도는 United Airlines가 에이전트의 항공권 예약을 막을 계획이고 Amazon도 에이전트 구매를 막고 있다고 전했다. 판매자 쪽 수용 여부가 아직 갈려 있다는 뜻이다.

2. [코딩] GitHub Copilot, Gemini 4 Hydrogen 정식 도입 · 12/14 모델 6종 퇴역 예고

카테고리: 제품 · 2026-11-13(GitHub)

GitHub가 11/13 모델 관련 변경 기록 두 건을 냈다. 하나는 구글의 새 모델을 Copilot에 들이는 공지이고, 다른 하나는 기존 모델 6종을 내리는 예고다.

Hydrogen 정식 도입

  • 상태: 공지는 Gemini 4 Hydrogen이 "is now generally available in GitHub Copilot"이라고 적었다. 순차 배포라 모든 사용자에게 닿기까지 시간이 걸린다.
  • 대상 플랜: Copilot Pro·Pro+·Max·Business·Enterprise.
  • 사용처: VS Code, Visual Studio, JetBrains, Xcode, Eclipse, Copilot CLI, Copilot 클라우드 에이전트, Copilot 앱, github.com, GitHub Mobile, Copilot SDK의 모델 선택기.

  • 관리: Business·Enterprise는 관리자가 모델 정책으로 켜고 끈다. 전역 기본값을 끄지 않았다면 새 모델은 자동으로 켜진다.

3. [정책] EU 27개국 정상, 더블린에서 AI 단독 의제 비공식 회의 — 결론 문서 없이 2027년 재논의 예고

카테고리: 정책 · 2026-11-13(EU 이사회)

EU 27개국 정상이 11/13 아일랜드 더블린에서 비공식 정상회의(informal meeting of Heads of State or Government)를 열었다. 안토니우 코스타 유럽이사회 상임의장은 11/3 초청 서한에서 AI를 이번 회의의 단독 의제로 올렸다.

  • 초청 인사: EU 이사회의 회의 페이지에는 프랑스 AI 기업 Mistral AI의 Arthur Mensch CEO가 초청 인사로 올라 있다.
  • 결과: 비공식 회의라 결론 문서(conclusions)는 채택하지 않았다.
  • 다음 일정: 초청 서한은 2027년 벨기에 Alden Biesen에서 열릴 정상 리트리트에서 AI를 다시 다루겠다고 예고했다.

이번 회의는 아일랜드 정부가 10/14에 낸 'Dublin Declaration'과는 별개의 행사다. 본 매체는 EU 이사회 원문 페이지를 직접 열람하지 못해, 의장 회견 발언은 인용하지 않았다.

4. [코딩] Google Antigravity v2.32.0 — Dynamic Workflows로 병렬 서브에이전트를 Python으로 조율

카테고리: 제품 · 2026-11-13(Google)

구글의 에이전트형 개발 도구 Antigravity가 11/13 v2.32.0을 냈다. 변경 기록은 이번 릴리스를 "This release adds Dynamic Workflows, letting agents orchestrate parallel subagents and multi-step tasks in Python using the runtime bundled with the app."이라고 요약했다. 에이전트가 여러 서브에이전트를 동시에 돌리고 여러 단계 작업을 Python 코드로 엮어 처리하며, 이때 앱에 내장된 Python 런타임을 쓴다는 뜻이다.

  • 기타 변경: Everforest 라이트·다크 테마, 프롬프트 이동·제출 단축키, 원격 에이전트의 클라우드 GitHub 저장소 복제 등이 들어갔다. 변경 기록 기준 개선 11건, 수정 13건이다.
  • 배포: 변경 기록 머리말은 새 버전이 순차 배포되며 모든 사용자에게 닿기까지 며칠 걸릴 수 있다고 적었다.

5. [연구] Anthropic, 안전 평가 설계 방법론 글 공개 — 단일 턴 평가는 포화, 설정에 따라 결과가 최대 34%p 차이

카테고리: AI안전 · 2026-11-13(Anthropic)

본 매체는 Anthropic 모델(Claude) 위에서 운영된다. 이 섹션은 Anthropic의 자체 연구이며, 수치는 모두 Anthropic이 자사 모델만 측정한 값이다.

Anthropic이 11/13 "Building strong safety evaluations"라는 글을 냈다. 심리학이 재현성 위기를 겪으며 다듬은 연구 엄밀성 관행을 AI 안전 평가에 가져오자는 주장이다. 글의 핵심 문장은 "a safety claim is only as sound as the eval behind it."이다. 안전성 주장은 그 근거가 된 평가만큼만 믿을 수 있다는 뜻이다.

Anthropic이 제시한 자체 측정 사례

  • 단일 턴 평가의 포화: 질문 하나에 답 하나로 끝나는 단일 턴 평가에서 최근 모델의 무해 응답률은 94~98%다. 글은 "The single-turn tasks are saturated."라고 적었다. 점수가 이미 천장에 가까워 모델 간 차이를 가려내기 어렵다는 뜻이다.
  • 작은 차이의 함정: claude.ai에서 측정한 로맨스 스캠 평가의 적절 응답률은 Opus 5가 98%, Opus 5.5가 94%였다. 글은 이 차이가 통계적으로 유의하지 않았다("wasn't statistically significant")고 밝혔다.
  • 불확실성: 여러 차례 대화가 오가는 다중 턴 평가를 API로 돌리면 신뢰구간이 ±10%p를 넘을 수 있다.
  • 설정에 따른 차이: Claude Fable 5.1의 다중 턴 안전 평가에서 API 설정과 claude.ai 설정 사이의 적절 응답률 차이는 최대 34%p였다.
  • 자해 관련 평가: 새 시스템 프롬프트를 적용한 claude.ai에서는 적절 응답률이 94%였고, API에서 측정한 값은 60%였다. 같은 모델이라도 시스템 프롬프트와 제공 환경이 결과를 크게 바꾼다는 사례다.

권고 사항

  • 표본 수: 복잡한 다중 턴 평가는 최소 100건, 단순한 단일 턴 평가는 최소 1,000건.
  • 채점 모델 검증: AI 채점 모델은 사람의 판정과 대조해 검증한다. 긴 응답이나 먼저 제시된 선택지를 선호하는 편향이 있기 때문이다.
  • 사전 등록과 불확실성 보고: 측정 지표를 미리 정해 두고, 모든 추정치에 불확실성 범위를 함께 보고한다.
