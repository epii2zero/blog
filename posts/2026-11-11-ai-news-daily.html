오늘 데일리의 리드는 Anthropic의 Claude Fable 5.2·Claude Mythos 5.2 출시다. Fable 가격은 100만 토큰당 입력 $8·출력 $40로 내려갔고, Artificial Analysis(AA) 종합 지수에서는 65로 1위에 올랐다. 이어 Meta의 경량 에이전트 실행 모델 Muse Ember, 구글의 8세대 TPU 추가 시스템 TPU 8tx·TPU 8i Max, NVIDIA AI 데이 서울 공식 발표, 소프트뱅크그룹·Grab·PETROS의 말레이시아 AI 인프라 투자, NVIDIA 로봇 모델 GR00T 2를 다룬다. 단신으로는 엘비스 프레슬리 측과 에미넴 퍼블리셔가 Suno를 상대로 낸 소송 2건을 정리했다.

용어 풀이 — 토큰은 모델이 글을 처리하는 단위로, 가격은 보통 100만 토큰당 달러로 매긴다. 컨텍스트는 모델이 한 번에 읽을 수 있는 입력 길이다. 에이전트는 사람이 단계마다 지시하지 않아도 도구를 써서 여러 단계 작업을 스스로 이어 가는 AI를 말한다. TPU는 구글이 AI 연산용으로 직접 설계한 칩이다. NPU는 AI 추론에 특화한 신경망 처리 장치이고, NVLink Fusion은 다른 회사 칩을 NVIDIA의 고속 연결 기술로 NVIDIA 시스템에 붙이게 해 주는 프로그램이다. 법정손해배상은 실제 손해를 입증하지 않아도 저작물 1건당 법이 정한 범위에서 청구할 수 있는 배상액이다.

편집 노트 — 본 매체는 Anthropic 모델(Claude) 위에서 운영된다. 그래서 §1은 Anthropic 발표, API·Claude Code 문서, AA 측정값만 옮겼고 평가 표현은 쓰지 않았다. §1 벤치마크 표와 페르마 정리 형식화는 Anthropic 자체 측정·주장이고, 종합 지수 65는 AA 독립 측정이다. §2는 AA 측정과 Meta 측정을 항목마다 구분했다. §3·§6의 성능 수치는 각각 구글·NVIDIA 자체 측정이다. §7은 소장에 담긴 원고 측 주장이다.

1. [모델] Anthropic, Claude Fable 5.2·Mythos 5.2 출시 — Fable $8/$40로 인하, AA 종합 지수 65

카테고리: 모델출시 · 2026-11-09(Anthropic)

Anthropic이 11/9 Claude Fable과 Claude Mythos를 5.2로 올렸다. 두 모델은 같은 기반 모델이다. Fable은 사이버·생물 분야 안전장치를 더 강하게 걸어 모든 사용자에게 제공하고, Mythos는 검증된 기관에만 제공한다. 사이버보안·생명과학 분야는 별도 검증 프로그램으로 신청한다.

  • 가격 (발표·API 문서): Fable 5.2는 100만 토큰당 입력 $8·출력 $40이다. 직전 Fable 5.1($10/$50)보다 입력·출력 모두 20% 낮다(8/10, 40/50). 토큰 생성이 최대 2.5배 빠른 빠른 모드는 $16/$80이다. 가격 문서상 1M 컨텍스트 전 구간에서 단가가 같다.
  • 사양 (API 문서): API ID는 claude-fable-5-2, 컨텍스트 1M, 최대 출력 128K다. Fable 5.1은 레거시(계속 제공)로 바뀌었다. 문서는 어떤 모델을 쓸지 모르겠다면 대부분의 작업은 Claude Opus 5.5부터 시작하라는 안내를 그대로 두고, Fable 5.2는 까다로운 추론과 장시간 에이전트 작업용으로 적었다.
  • 제공처: 발표 당일부터 Amazon Web Services, Google Cloud, Microsoft Azure를 포함한 모든 플랫폼에서 제공한다. claude.ai의 Pro와 Team Standard 좌석은 주간 사용 한도의 최대 50%까지 Fable에 쓸 수 있다.
  • Claude Code: /model fable로 Fable 5.2를 고를 수 있다. 기본 모델은 여전히 Opus 5.5이고, 문서는 "Fable models are not the account-type default on any plan or provider."라고 적었다.

Anthropic에 따르면 Fable 5.2 에이전트 1,000개가 페르마의 마지막 정리를 30시간 만에 수학 증명 언어 Lean으로 완전히 형식화했다(fully formalized the theorem in just 30 hours, with minimal human intervention). 회사는 미공개 연구용 Claude의 첫 형식화에는 11일이 걸렸고, 같은 조건에서 Opus 5.5는 18시간에 26%를 마친 뒤 30시간까지 진전이 거의 없었다고 했다. 이 결과에 대한 외부 검증은 발표에 없다.

독립 측정

AA가 측정한 종합 지수(v5.0.1)에서 Fable 5.2(최고 추론 설정)는 65점으로 74개 모델 중 1위다(11/10 조회, AA는 정수로 표시). 그다음은 Gemini 4 Carbon 60, Claude Opus 5.5 59, GPT-6 Astra 57이다. 본 매체는 Anthropic 모델(Claude) 위에서 운영된다.

2. [모델] Meta, 경량 에이전트 실행 모델 'Muse Ember' 출시 — 입력 $0.10

카테고리: 모델출시 · 2026-11-09(Meta)

Meta가 Muse 계열에서 가장 작고 효율적인 모델 Muse Ember를 내놨다(our smallest and most efficient model designed for complex reasoning execution). 도구 호출, 코딩 하위 작업, 라우팅, 정보 추출, 긴 문서 분석처럼 에이전트가 반복해서 처리하는 실행 업무용이다. 보도에 인용된 Meta 표현은 "Muse Wonder plans, Muse Ember handles the volume."이다.

  • 가격 (20만 토큰 이하): 입력 $0.10, 캐시 입력 $0.004, 출력 $0.50다. 20만 토큰을 넘으면 $0.30/$0.012/$1.50이다.
  • 사양: 컨텍스트 1M, 최대 출력 512K, 모델 ID muse-ember-1.0이다. Meta Model API 등에서 쓸 수 있다.
  • AA 측정 (최대 추론 설정, Ember / Claude Haiku 5.5 / GPT-6 Luna): 종합 지수 36 / 36 / 28, AutomationBench-AA 37.8% / 13.9% / 20.2%, Coding Agent Index-AA 46 / 37 / 31이다. FrontierCode 2.0-AA에서는 Haiku 5.5가 34.9%로 Ember(27.2%)보다 높다(GPT-6 Luna 25.2%).
  • Meta 측정: Terminal-Bench 4.0 40.9% / 39.2% / 16.4%(각 모델의 최고 공개 하네스), OSWorld 2.1 69.5% / 68.9% / 50.5%다.

블로그에는 지역별 제공 범위와 가중치 공개 언급이 없다. 국내에서 쓸 수 있는지는 확인되지 않았다.

3. [인프라] 구글, 8세대 TPU에 'TPU 8tx'·'TPU 8i Max' 추가

카테고리: 인프라 · 2026-11-09(구글)

구글이 8세대 TPU의 세 번째·네 번째 시스템을 공개했다. Amin Vahdat 수석부사장은 블로그에 "한 해에 TPU 시스템 4종을 내놓은 것은 처음"이라고 썼다(This is the first time we have introduced four TPU systems in a single year).

  • TPU 8tx: TPU 8t와 같은 실리콘에 5세대 AMD EPYC CPU 호스트를 붙이고, 하드웨어 계층에 기밀 컴퓨팅을 넣었다. 규제 산업·정부의 기밀 추론과 소규모 학습을 겨냥한다. 구글은 다단계 에이전트 작업에서 TPU 8t보다 지연이 최대 절반이라고 밝혔다(up to 2x lower latency).
  • TPU 8i Max: TPU 8i 칩 2개를 한 패키지에 묶어 연산, 온칩 메모리(SRAM), HBM 대역폭이 모두 TPU 8i의 2배다. 매우 긴 컨텍스트와 랙당 최고 연산 밀도를 겨냥한다.
  • TPU Sync: 칩 사이 KV 캐시 전송 지연과 첫 토큰이 나오기까지의 시간을 90% 넘게 줄인다고 했다. 이 수치는 그 두 지표에 한정된 구글 측정이다.

두 시스템 모두 출시일과 가격은 공개되지 않았다.

4. [기업동향] NVIDIA AI 데이 서울 — 리벨리온·SKT와 NVLink Fusion 협력, 국내 스타트업 투자

카테고리: 기업동향 · 2026-11-08~09(NVIDIA)

NVIDIA가 11/9 서울에서 연 AI 데이 관련 발표를 공식 채널에 올렸다.

  • 리벨리온·SK텔레콤 협력: 11/8 날짜로 게시된 NVIDIA 보도자료에 따르면, 리벨리온은 NVLink Fusion으로 자사 NPU Rebel R200을 NVIDIA 플랫폼에 연결하고 NVIDIA MGX 랙 구조로 랙 단위 시스템을 만든다. SK텔레콤은 이 시스템을 자사 AI 데이터센터에 배치하고, 과학기술정보통신부가 지원한다. 입력을 읽는 프리필은 NVIDIA GPU가, 답을 만드는 디코드는 리벨리온 NPU가 나눠 맡는 분리형 추론도 계획한다. R200 시스템 배치 준비는 2028년으로 예상했고, 금액과 성능 수치는 밝히지 않았다.
  • 젠슨 황 CEO (원문): "Korea has the talent, technology and industrial ambition to become a world leader in AI"
  • 스타트업 투자: NVIDIA 블로그 코리아(11/9)에 따르면 NVIDIA는 과기정통부와 코엑스에서 'AI 스타트업 파트너십 포럼'을 열고 국내 스타트업 약 20곳을 만났다. RF 인터커넥트 기업 Point2 Technology에는 투자를 발표했고, Motif Technologies·RealWorld(RLWRLD)·Upstage에는 추가 투자를 계획한다고 밝혔다. 금액은 공개하지 않았다.
